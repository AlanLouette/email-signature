# Générateur de signature e-mail

Générateur statique en français : coordonnées, formule de politesse, logo importé,
couleur, police système et icônes. Aperçu immédiat et panneau sticky sur ordinateur.

Ouvrir `index.html` dans un navigateur, ou le servir en HTTPS pour la copie enrichie.
Aucune installation ni compilation nécessaire. Pour intégrer le générateur à un site,
héberger ce fichier et l’afficher dans une iframe, ou adapter son HTML/CSS/JavaScript.

Les images importées sont traitées localement dans le navigateur. La police Outfit
est chargée depuis Google Fonts pour l’interface uniquement ; la signature utilise
les polices système sélectionnées avec des polices de remplacement.

Après collage dans Gmail ou Outlook, vérifier le rendu : certains éditeurs filtrent
les images intégrées. Le logo peut alors être inséré directement dans leur éditeur.
